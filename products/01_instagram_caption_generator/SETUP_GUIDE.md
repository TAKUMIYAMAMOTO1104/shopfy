# 美容室専用 Instagram投稿キャプション 30日分自動生成ツール
## セットアップガイド（購入者向け）

所要時間：約10分。プログラミング知識ゼロでもOKです。

---

## 1. Gemini APIキーを取得（無料）

1. ブラウザで [Google AI Studio](https://aistudio.google.com/app/apikey) にアクセス
2. Google アカウントでログイン
3. 「Create API key」をクリック
4. 表示された API キー（`AIza...` で始まる文字列）をコピーして控える

> **無料枠**: 1分あたり15リクエストまで無料。本ツールの利用範囲では完全無料で使えます。

---

## 2. Googleスプレッドシートを準備

1. [Googleドライブ](https://drive.google.com) を開く
2. 「新規」→「Googleスプレッドシート」で空のシートを作成
3. シート名を「美容室Instagram投稿管理」などに変更

---

## 3. スクリプトを貼り付け

1. メニューから「拡張機能」→「Apps Script」をクリック
2. 開いたエディタの中身を全て削除
3. 同梱の `instagram_caption_generator.gs` の内容を全てコピーして貼り付け
4. 上部の「プロジェクト名」を「Instagram キャプション生成」などに変更
5. フロッピーアイコンで保存

---

## 4. APIキーを登録

1. Apps Script 画面の左メニューから歯車アイコン「プロジェクトの設定」をクリック
2. 下にスクロールして「スクリプト プロパティ」セクション
3. 「スクリプト プロパティを追加」をクリック
4. 以下のとおり入力：
   - プロパティ：`GEMINI_API_KEY`
   - 値：手順1でコピーしたAPIキー
5. 「スクリプト プロパティを保存」をクリック

---

## 5. スプレッドシートで実行

1. スプレッドシートのタブに戻る（**ブラウザを一度リロード**）
2. メニューバーに「キャプション生成」が新しく表示される
3. 「キャプション生成」→「店舗情報シートを初期化」をクリック
4. 初回のみ「承認が必要です」と出るので、画面の指示どおり許可
   - 「詳細」→「（プロジェクト名）に移動」→「許可」
5. 「店舗情報」シートが作成されるので、B列に自店舗の情報を記入

---

## 6. キャプション生成

1. まずは「キャプション生成」→「**1日分だけ生成（テスト用）**」で動作確認
2. 「生成キャプション」シートに1件出力されたらOK
3. 続けて「キャプション生成」→「**30日分一括生成**」を実行
4. 30〜60秒待つと、30日分のキャプションが完成

---

## 出力されるもの

| 列 | 内容 |
|---|---|
| Day | 1〜30 |
| 投稿予定日 | 今日を起点に自動で日付セット |
| カテゴリ | スタイル紹介 / お役立ち情報 / 雰囲気紹介 / お客様の声 / キャンペーン |
| テーマ | その日の投稿テーマ |
| キャプション | フック・本文・CTA・ハッシュタグ全部入りの完成形 |
| 撮影指示 | どんな写真を撮ればいいかの指示 |
| ステータス | 未投稿 / 投稿済 を手動で管理 |

---

## 困ったとき

**Q. 「店舗情報シートがありません」と出る**
A. 「店舗情報シートを初期化」を先に実行してください。

**Q. 「GEMINI_API_KEY が未設定です」と出る**
A. 手順4を見直してください。スペル間違い注意（大文字小文字も完全一致）。

**Q. APIエラー (429) が出る**
A. 短時間に連続実行しすぎです。1分ほど待って再実行してください。

**Q. 出力された文章を変更したい**
A. シート上で直接編集できます。気に入ったフレーズに調整してください。

**Q. 来月分も生成したい**
A. 同じ手順で「30日分一括生成」を再実行すれば、シートが上書きされます。バックアップが必要なら、シートを複製してから実行してください。

---

## 推奨運用フロー

1. **月初**：30日分一括生成
2. **撮影日**（週1〜2回）：撮影指示に従って店内・スタイル写真を撮影
3. **投稿時**：キャプション列をコピー → Instagramに貼り付け → 写真添付
4. **投稿後**：ステータスを「投稿済」に変更

これで Instagram 運用にかかる時間が **月20時間 → 月3時間** に短縮されます。
